## About Me

### Turning chaos into harmony

I’m a software engineer with a passion for C++ and learning diverse systems. I've worked across gameplay, multiplayer networking, engine tools, UI with Qt, Slate, and Android, backend microservices, and Android apps. I like untangling gnarly systems and leaving them faster, clearer, and kinder to the next engineer. I've done extensive work in Unreal Engine tooling, CI/CD, and cross-platform automation. Some tools I've created for Unreal Engine include functional test frameworks, device orchestration, performance telemetry, crash reporting pipelines, and large-scale asset verification. Before games, I shipped at DirecTV/AT&T across the full stack, from Linux kernel configuration and driver layer debugging to Android TV UI and backend services, all while helping teams reach sprint-based Android TV releases with Google certification. My number one engineering goal is simple: make working software that people genuinely enjoy using.
